# 三维钩织

一个可以装到手机、平板和电脑上的钩织应用。先看线怎么走，再跟着钩完一块祖母方格杯垫，最后把四块方格接成一只小袋。

界面是中文。针法、杯垫和小袋用的是同一套针目图：每一针都有入针位置和一根参数曲线，教学和构织看到的是同一根线。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开终端里给出的地址。手机和电脑可以同时开。

```bash
npm run typecheck
npm run lint
npm run check
npm run build
npm run preview
```

`check` 会核对锁针、长针、祖母方格的边针数，以及小袋接缝是否对齐。

## 里面有什么

- **学**：钩针和线、锁针、引拔针、短针、中长针、长针、加减针，然后把第一圈方格走一遍。圆球和魔法环放在主路之后。
- **做**：锁针带、祖母方格杯垫、四方小袋。可以按针记数，画面跟着长出来。
- **组**：方格、带子、锁针带、圆片、圆球、耳朵。针数对不上会提醒，并可以先预览调整。
- **我的**：进度、线材笔记、用线估算、左右手、速度和减少动效。

图解可以复制。构织台可以复制一条链接，打开就能看到同一件作品。

## 安装到设备

构建产物是静态文件，带有 manifest 和 service worker。用浏览器的「添加到主屏幕」或「安装应用」即可。

## 部署静态预览

`vite.config.ts` 里的 `base` 是 `./`，适合 GitHub Pages 这类静态托管。

仓库里有 `.github/workflows/pages.yml`。推到 `main` 之后，在仓库 Settings → Pages 里把来源选成 GitHub Actions，就会发布 `dist`。

也可以在本地 `npm run build`，把 `dist` 目录交给任何静态服务器。

## 画面

工作台是亚麻色，灯光按摄影棚来配：暖的主光、一点冷的补光，线有捻向和绒毛感。默认没有网格，也没有灰背景。
